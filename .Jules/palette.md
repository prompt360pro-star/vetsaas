## 2026-04-22 - Accessible Form Controls
**Learning:** When building reusable form controls (Input, Textarea, Select) in React, using `useId()` to generate fallback IDs ensures that `<label>` elements are properly linked to their inputs via `htmlFor`, even if the consumer forgets to provide an `id`. Additionally, dynamically linking errors or hints via `aria-describedby` while explicitly excluding hints when an error is present helps screen readers prioritize critical validation feedback. Decorative elements like the visual required asterisk (`*`) must include `aria-hidden="true"` to prevent screen readers from confusingly announcing 'star' next to labels.
**Action:** Always include `useId()` for fallback ID generation in custom form components and rigorously manage `aria-describedby` to surface the most relevant feedback (error vs hint) to screen readers. Apply `aria-hidden="true"` to all decorative visual elements.
