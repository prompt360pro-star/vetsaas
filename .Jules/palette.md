## 2024-10-17 - Dynamic Accessibility IDs in Reusable React Form Components
**Learning:** When building reusable UI components (like `Input`, `Select`, `Textarea`), accessibility attributes like `aria-describedby` and label `htmlFor` bindings fail if developers don't explicitly pass an `id` prop. Additionally, spreading `...props` at the end of an input element can overwrite internally generated accessibility attributes if the consumer passes custom values.
**Action:** Use React's `useId()` hook to generate a robust fallback `id`. Combine it with any `id` and `aria-describedby` passed via props to create a unified accessible experience. Crucially, destructure accessibility-related props before spreading `...props` to ensure custom attributes are merged properly rather than overwritten.
