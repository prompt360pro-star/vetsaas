## 2024-05-18 - Form Field Accessibility\n**Learning:** Implementing fallback IDs using React's `useId()` ensures that all form fields correctly associate labels, errors, and hints for screen readers even when developers omit explicit IDs.\n**Action:** Use `useId()` and `aria-describedby` as standard boilerplate when creating new form controls in this design system, and hide decorative elements like required asterisks with `aria-hidden='true'`.
