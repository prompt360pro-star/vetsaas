## 2023-10-25 - [Form Component Accessibility Overhaul]
**Learning:** React UI components need dynamic fallback IDs for robust accessibility. While developers often forget to pass `id` props, screen readers require unique identifiers to properly associate `<label htmlFor>` and `aria-describedby` elements (like error states or hints) with the interactive input. Additionally, decorative icons and required asterisks read out as disruptive noise if not explicitly hidden.
**Action:** Always utilize React's `useId()` in fundamental form components (Inputs, Selects, Textareas) to ensure every instance has a unique ID by default. Use this generated ID to dynamically construct and link error/hint IDs via `aria-describedby`. Explicitly set `aria-hidden="true"` on non-semantic visual indicators.
