## 2024-03-24 - React Accessible Form IDs and ARIA Attributes
**Learning:** Using React's `useId()` is crucial for generating unique fallback IDs to associate `<label htmlFor>` with form inputs when an explicit `id` prop isn't provided. Furthermore, dynamically assigning `aria-describedby` based on the presence of an `error` or `hint` must properly resolve to `undefined` instead of an empty string, allowing React to remove the attribute entirely and ensuring clean accessible name computation. Visual-only form artifacts like asterisks (`*`) or input icons should also be decorated with `aria-hidden="true"`.
**Action:** When implementing new form inputs, textareas, or selects, prioritize `id` props with a `useId()` fallback, explicitly connect error/hint blocks via `aria-describedby`, and silence non-semantic visual indicators.
