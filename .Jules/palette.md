## 2024-09-07 - Dynamic ID and ARIA Association in React Form Components
**Learning:** In highly reusable React form components, relying on consumers to pass an `id` often results in unlinked `<label>` elements and missing `aria-describedby` associations for inline hints and errors, breaking screen reader context. Furthermore, explicitly writing out a visually distinct required asterisk is read aloud redundantly alongside native 'required' semantics.
**Action:** Use React's `useId()` to generate a consistent fallback ID. Always link the `<label htmlFor={id}>` to `<input id={id}>`. Construct dependent IDs (e.g., `${id}-error`) and bind them dynamically using `aria-describedby`, ensuring non-existent elements are filtered out. Mask visual required indicators with `aria-hidden="true"`.
