## 2024-08-04 - Accessibility Improvements for Form Controls\n**Learning:** Relying solely on developers to provide unique `id` props for form inputs often results in unlinked labels and error messages. Decorative elements like `*` for required fields can cause auditory clutter for screen reader users.\n**Action:** Use React `useId()` to guarantee a fallback `id` for `<label htmlFor>` bindings. Link errors/hints using dynamically generated IDs passed to `aria-describedby`. Explicitly hide purely visual cues (like `*` or icons) from assistive tech using `aria-hidden="true"`.
