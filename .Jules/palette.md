## 2026-04-15 - Dynamic Accessibility IDs in Form Components
**Learning:** Hardcoding or entirely omitting `id`/`htmlFor` mappings breaks screen reader accessibility for reusable UI components. Furthermore, conditionally applying `aria-describedby` based on the presence of `hint` or `error` is required so that empty text nodes aren't unnecessarily announced. Using `undefined` instead of empty strings ensures React removes the attribute entirely when not needed. Decorative elements, like a visual red `*` for required fields, must explicitly use `aria-hidden="true"` to prevent screen reader clutter.
**Action:** Always utilize React's `useId()` hook to generate robust fallback `id` strings for base input components, enabling programmatic linkage of labels and dynamic `aria-describedby` associations.
