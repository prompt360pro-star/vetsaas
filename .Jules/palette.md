## 2024-05-24 - Programmatic Association of Labels and Errors/Hints
**Learning:** React's `useId()` is crucial for generating unique IDs to associate `<label>` elements with their respective form inputs via `htmlFor`, and inputs with their validation errors or hint text via `aria-describedby`. This ensures that screen readers can correctly announce field purposes and validation states even when multiple instances of the same component are rendered. When an error is present, hint text should be excluded from `aria-describedby` to prioritize validation feedback for screen readers.
**Action:** When building custom form components like `Input`, `Textarea`, and `Select` in React, always utilize `useId()` to dynamically generate `id` values if they aren't explicitly passed as props. Use these IDs for the input's `id` attribute, the label's `htmlFor` attribute, and any associated error or hint text containers, which should then be linked back to the input using `aria-describedby`.
