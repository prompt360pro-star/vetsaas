## 2024-05-05 - React Server/Client Components Form Accessibility
**Learning:** When building accessible form components in a Next.js/React app, it's a critical pattern to use `useId()` to generate fallback unique IDs (prioritizing explicitly provided `id` props). This ensures `<label htmlFor="...">` bindings are robust even when an ID isn't provided by the parent. Additionally, setting `aria-hidden="true"` on decorative elements like required asterisks (`*`) prevents screen readers from redundantly announcing them, and `aria-describedby` attributes should conditionally omit hint text when an error is present to prioritize validation feedback for screen readers.
**Action:** Always wrap standard inputs, selects, and textareas in this pattern to guarantee accessibility out of the box.
