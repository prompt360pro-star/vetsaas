## 2025-04-03 - Form Component Element Association and Error Hint Priority
**Learning:** Screen readers and accessibility tools require explicit linking between labels and form controls using `htmlFor` and `id` attributes. Additionally, using `aria-describedby` dynamically allows linking error messages or hint texts. Crucially, when an error is present, hint text is programmatically excluded from `aria-describedby` to prioritize validation feedback and avoid overwhelming users with multiple descriptions.
**Action:** Always generate unique IDs via `useId()` for form components and associate them to labels. Use `aria-invalid` to denote error states and dynamically map `aria-describedby` to either the error message (prioritized) or hint text to ensure accessible name computation logic works flawlessly without confusing users.
