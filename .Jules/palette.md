## 2026-07-22 - Improve form field accessibility\n**Learning:** When generating IDs for inputs using `useId()`, it's critical to conditionally set `aria-describedby` to `undefined` when errors or hints are not present. Setting it to an empty string can cause screen readers to incorrectly parse the attribute, and referencing a non-existent element's ID breaks accessibility guidelines.\n**Action:** Always conditionally format optional ARIA IDs (e.g., `const ariaDescribedBy = [errorId, hintId].filter(Boolean).join(' ') || undefined;`) when building reusable form components.
