## 2026-07-07 - Automatic Form Input Associations\n**Learning:** In React components like Input, Select, and Textarea, the absence of an explicit `id` prop often leads to orphaned labels and unassociated error/hint messages. Developers frequently forget to pass IDs to form controls, severely impacting screen reader navigation.\n**Action:** Use React's `useId()` as a fallback when `props.id` is missing. This ensures `<label htmlFor>` bindings and `aria-describedby` associations always function correctly out-of-the-box, providing a robust and accessible developer experience.
