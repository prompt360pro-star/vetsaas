## 2024-08-26 - Form Accessibility Polish
**Learning:** React form UI elements frequently miss standard fallback `id`s for implicit `<label htmlFor>` bindings or have incomplete accessibility implementations, especially around error handling or nested dynamic elements. Also, simple structural indicators (like `*` for required) are not hidden by default from screen readers, creating clutter.
**Action:** Consistently use `useId()` to generate a guaranteed fallback `id` when wrapping inputs/textareas/selects. Explicitly use `aria-describedby` dynamically tying elements to their hint or error blocks if present. Hide pure visual decorators like asterisks or decorative loading icons with `aria-hidden="true"`. Use `aria-label` manually passed from props for non-text toggles like `Switch`.
