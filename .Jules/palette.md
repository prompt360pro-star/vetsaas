## 2026-05-04 - Form Element Accessibility
**Learning:** For reusable form components (Input, Select, Textarea), relying solely on implicit label wrapping isn't always enough for robust screen reader support, especially when integrating with complex React states or form libraries. Furthermore, decorative elements like the required asterisk (`*`) or input icons are announced by screen readers if not explicitly hidden. Additionally, `aria-describedby` must be conditionally applied and reference valid dynamic IDs (e.g. for errors or hints) to properly associate descriptive text with the form control.
**Action:** Always use `useId()` to generate fallback IDs for form controls to explicitly bind `<label htmlFor={id}>` to the input element. Ensure decorative elements use `aria-hidden="true"`, and conditionally apply `aria-describedby` using the matching IDs of error or hint elements.
