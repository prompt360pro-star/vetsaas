## 2024-06-12 - Input component accessibility fixes\n**Learning:** The project's central React Input primitive lacked intrinsic association between the input elements and their hint/error states, meaning screen readers missed contextual validation context. Furthermore, asterisks for required fields and visual decorative icons were being announced to assistive devices.\n**Action:** Implemented automatic ID generation utilizing 'useId' to intrinsically link labels (via htmlFor) and supplemental descriptions (via aria-describedby) independently. Decorative parts were muted with aria-hidden. This establishes a stronger a11y baseline pattern to use for other form primitives like Select, Textarea, and Checkbox.
