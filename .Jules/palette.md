## 2026-04-13 - Form Accessibility Standardization\n**Learning:** Dynamic generation of ARIA relationships (e.g., `aria-describedby`) using React's `useId` inside low-level form components (`Input`, `Textarea`, `Select`) ensures screen reader context is intrinsically provided without relying on developers to explicitly pass unique IDs at the usage site. Adding `aria-hidden='true'` to required asterisk indicators prevents redundant visual noise for AT users.\n**Action:** Use the `id ?? useId()` fallback pattern for all new interactive UI components that pair elements (e.g., labels, descriptions, errors) to ensure robust accessibility defaults.
