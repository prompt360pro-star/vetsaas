## 2024-07-01 - Improve Form Component Accessibility\n**Learning:** In highly customized React UI components, explicitly passing an ID via props is often overlooked by developers. Hardcoding or failing to handle ID fallbacks breaks accessibility mapping for `<label>` and `aria-describedby` when these components are rendered dynamically or multiple times on a page.\n**Action:** Standardized form components (`Input`, `Textarea`, `Select`) to dynamically generate and link fallback IDs using `useId()` if `props.id` is not explicitly provided. Also correctly scoped and handled optional `aria-describedby` values for hint/error conditions so screen readers don’t read empty attributes.
