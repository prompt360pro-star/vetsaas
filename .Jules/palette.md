## 2026-09-02 - Generate IDs for Form Controls\n**Learning:** In React UI components (e.g., Input, Textarea, Select), developers often forget to pass an explicit id prop. This leaves <label htmlFor> bindings and aria-describedby references disconnected, breaking screen reader functionality.\n**Action:** Always use React's useId() to generate a fallback ID. Explicitly bind label[htmlFor] to control[id], and properly construct and link conditional aria-describedby for error/hint elements.
