## 2026-05-13 - Component Accessible Linking Pattern
**Learning:** React's `useId()` hook provides a robust fallback for creating unique `htmlFor`, `id`, and `aria-describedby` relationships in reusable form components (`Input`, `Textarea`, `Select`) when explicit `id` props aren't provided by the parent. Also learned that when generating `aria-describedby`, if an error message exists, hint text can be programmatically omitted to prioritize validation feedback for screen readers. Furthermore, decorative visual markers like the required asterisk (`*`) should be hidden using `aria-hidden="true"` since the semantic `required` property is sufficient for screen readers.
**Action:** Apply this pattern (`useId` fallback + conditional `aria-describedby` prioritization + hidden decorative asterisks) as the standard approach when building or refactoring shared UI form control components in this design system.
