## 2024-05-19 - Form Controls Accessibility Linkage
**Learning:** React UI components need robust accessibility linkages that don't rely on developers passing explicit IDs. When mapping attributes like `aria-describedby` dynamically based on state (errors, hints), the IDs provided to screen readers must exactly match elements that are actually rendered in the DOM to avoid referencing "ghost" elements. Additionally, purely visual required indicators like asterisks (`*`) need to be explicitly hidden from screen readers using `aria-hidden="true"`.
**Action:** Use `useId()` to guarantee an `id` is always available for `htmlFor` and `<input id>` bindings. Conditionally render `aria-describedby` IDs by dynamically computing them (e.g., `const hintId = (hint && !error) ? \`${id}-hint\` : undefined;`) and ensuring they resolve to `undefined` rather than empty strings when not needed so React drops the attribute cleanly.
