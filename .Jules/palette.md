## 2024-05-15 - Dynamic ID generation for labels and screen reader prioritization
**Learning:** In form components (`Input`, `Textarea`, `Select`), using React's `useId()` to generate fallback unique IDs (prioritizing explicitly provided `id` props) for linking `<label>` via `htmlFor` is essential. Also, when setting `aria-describedby`, hint text should be programmatically excluded when an error is present to prioritize validation feedback for screen readers. Decorative elements like `lucide-react` icons (e.g., `Loader2`) and visual-only required asterisks `*` must include `aria-hidden="true"` to prevent screen readers from announcing them unnecessarily, ensuring clean accessible name computation.
**Action:** Always use `useId()` to link labels to inputs, handle `aria-describedby` logic carefully to prioritize errors, and consistently apply `aria-hidden="true"` to decorative icons and required asterisks.
