## 2024-04-12 - Missing htmlFor and aria-describedby in core form components
**Learning:** Found a recurring pattern in the core UI form components (`Input`, `Select`, `Textarea`) where the `<label>` lacked the `htmlFor` attribute linking to the inputs. In addition, the error and hint texts were visually rendered near the fields but lacked `aria-describedby` mappings, meaning screen reader users wouldn't have validation errors or hints read out when focusing the input. We applied the pattern found in memory to use `useId` to generate a fallback ID, map it to `htmlFor`, and dynamically assign `aria-describedby` prioritizing validation feedback over hints.
**Action:** When inspecting form controls, verify the presence of `htmlFor` in labels and `aria-describedby` matching the `id` of adjacent helper/error text nodes. Ensure unique ID generation is safely handled (e.g., React's `useId`) to prevent duplicate IDs in multi-instance form components.
