## 2024-04-16 - Form Field Association Patterns
**Learning:** In reusable form components (`Input`, `Textarea`, `Select`), unlinked labels (`<label>` without `htmlFor`) and unassociated error/hint text severely degrade screen reader experiences, as users rely on these programmatic associations to understand field purpose and validation states.
**Action:** Always use React's `useId()` hook to generate unique fallback IDs for form controls. Prioritize explicitly provided `id` props, link `<label>` via `htmlFor`, and dynamically set `aria-describedby` to the error or hint text IDs. When conditionally rendering attributes like `aria-describedby`, passing `undefined` rather than an empty string ensures React removes the attribute cleanly. Hide decorative asterisks with `aria-hidden="true"`.
