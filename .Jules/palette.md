## 2024-05-24 - Dynamic ID Generation for Form Accessibility
**Learning:** For React custom form components like `Input`, `Textarea`, and `Select`, dynamically associating elements via `htmlFor` and `aria-describedby` when explicit IDs are not provided can be elegantly handled using React's `useId()` hook. This ensures labels properly target their corresponding inputs even if the component is used multiple times on the same page. Additionally, setting `aria-describedby` dynamically depending on whether an error or hint is present ensures that screen readers prioritize the error correctly without causing invalid ARIA references when those descriptions don't exist.
**Action:** When creating or updating custom form controls, always generate a fallback unique ID using `useId()`, link `<label>` using `htmlFor`, dynamically build string arrays for `aria-describedby` based on available descriptive elements, and set visual-only adornments (like icons and asterisks) to `aria-hidden="true"`.
