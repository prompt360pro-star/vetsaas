## 2024-05-18 - [Add fallback useId and dynamic accessibility links to form controls]
**Learning:** React form controls like Input, Textarea, and Select need a fallback ID if one isn't explicitly provided, as screen readers rely on explicit `htmlFor` and `id` bindings to associate labels. In addition, `aria-describedby` configuration for errors and hints should be dynamically calculated (and completely removed if undefined) to prevent screen readers from reading empty or invalid elements, which improves the overall accessibility experience for form controls.
**Action:** Always use `useId()` in standard reusable UI components to guarantee a unique ID for `htmlFor` label bindings. Construct `aria-describedby` arrays and `.filter(Boolean).join(' ') || undefined` to conditionally omit references to non-rendered hints/errors.
